# Placeholder sprites

These original 32 x 32 PNG sprites are generated by `engine.pygame_renderer` from
the palette and shapes in `assets/catalog.py`. They require no downloaded artwork.
Regenerate them with:

```bash
gameworldlm assets --output-dir assets/placeholder
```

The renderer loads packaged sprites here. If they are absent it builds the same
surfaces in memory. Replace these PNGs to change presentation without changing
the world schema. Terrain textures are tiled; each structure or entity occupies
one scaled sprite across its footprint so its visual count matches its token count.
